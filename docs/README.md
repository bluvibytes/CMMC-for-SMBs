# Docs

Supporting educational material for CMMC for SMBs.

## CMMC Buyer's Guide

`CMMC-Buyers-Guide.pdf` is a vendor-neutral, plain-English guide to buying CMMC services without overpaying. It covers what CUI is, what Level 1 and Level 2 require, scoping as the biggest cost lever, honest cost ranges, red flags in consultant quotes, and the questions to ask a C3PAO.  Skip to slide 20 for additional free and low cost resources before you sign a contract.
